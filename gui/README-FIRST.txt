UEWorkshopScanner Desktop (Experimental)
========================================

1. Extract the complete ZIP. Do not run the app from inside the archive.
2. Keep UEWorkshopScanner.exe, oo2core_9_win64.dll, BINARY-EULA.txt, and the
   other included files together.
3. Start UEWorkshopScanner.exe as your normal Windows user.
4. On first launch, read the complete bundled-binary terms shown by the app.
   Continue only if you accept them.
5. Drop a MECCHA CHAMELEON Workshop map folder onto the app, or choose it with
   the Browse button, then select Scan this map.

Meccha Workshop maps are normally stored below:

  <SteamLibrary>\steamapps\workshop\content\4704690\<WorkshopItemId>

The scanner works locally. It does not upload or execute map contents.

UEWorkshopScanner is experimental. A clean result reduces risk but cannot prove
that a map is safe. Keep Windows Security or another antivirus enabled.
