# Changelog

## 0.1.0

- Added automatic pre-mount scanning for MECCHA CHAMELEON Workshop maps.
- Added fail-closed handling and a visible native warning for maps that do not
  pass scanning.
- Added first-run Binary EULA review and acceptance before protection activates.
- Added exact MECCHA CHAMELEON and UE4SS compatibility checks with visible
  warnings for unsupported builds.
- Removed reverse-engineering hotkeys from the distributable runtime.
- Added package layouts for GitHub, Thunderstore, and Nexus Mods.
