UEWorkshopScanner alpha.3 adds an experimental desktop scanner for players who
do not want to use a command line.

## Downloads

- `UEWorkshopScanner-0.1.0-alpha.3-desktop-windows-x64.zip` — recommended for
  players. Extract the complete ZIP, start `UEWorkshopScanner.exe`, complete
  the one-time terms review, and choose a Workshop map folder.
- `UEWorkshopScanner-0.1.0-alpha.3-cli-windows-x64.zip` — command-line scanner
  for advanced users, automation, and integrations.

Each archive has a matching `.zip.sha256` download and an internal
`SHA256SUMS` manifest. Both complete archives include the approved Oodle
decoder, full binary EULA, MIT license, third-party notices, and generated Rust
dependency license inventory.

## What changed

- Added a compact Dioxus desktop interface with drag-and-drop folder selection
  and plain-language Allow, Review, Block, or Incomplete results.
- Added full first-run bundled-binary terms and explicit acceptance inside the
  desktop app.
- Reused the same Rust scanner library from both the CLI and GUI. Players do
  not need to install or configure a separate CLI.
- Added adaptive window sizing: compact while choosing a map and larger while
  scanning or displaying results.
- Made Meccha desktop scans require Oodle readiness before `retoc` reads any
  chunks. Missing decoder or EULA setup now produces one actionable error
  instead of a repeated initialization-failure cascade.
- Added decoder-free desktop artifacts to CI for advanced testing.

## Scope

The desktop app performs manual local scans. It does not install the UE4SS
automatic-protection mod or hook the game. The separately tested Meccha
integration remains available from the alpha.2 prerelease.

UEWorkshopScanner is experimental defense in depth. An Allow result does not
prove a map is safe, and the scanner can produce false positives, false
negatives, incomplete results, or errors. Keep Windows and antivirus protection
enabled.
